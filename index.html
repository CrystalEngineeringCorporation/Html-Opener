เปิดไฟล์ HTML

เลือกไฟล์ .html จากเครื่องหรือวางโค้ด แล้วดูผลได้ทันทีบนไอโฟน

เปิดล่าสุด

    ยังไม่มีไฟล์ที่เปิดไว้ ไฟล์ที่เปิดจะถูกเก็บในเบราว์เซอร์นี้เท่านั้น

    รองรับไฟล์ HTML ไฟล์เดียวที่มี CSS และ JavaScript อยู่ในไฟล์ ถ้าไฟล์เรียกใช้ CSS JS หรือรูปที่แยกอยู่ในเครื่อง ส่วนนั้นจะไม่แสดง ต้องรวมเข้าไฟล์เดียวก่อน
